# Compatibility review — 23 October 2026

Reference: AzuraCast `19d68c47b1e4d569885ca7cf4c40609cbabefda7`, Liquidsoap 2.4.5,
PHP 8.4. Review/import workflows added during development have been removed from
the plugin. Its scope is sweeper configuration, playback and the numeric
`intro_end` custom field.

## Addressed playback issues

- The generated AutoDJ factory now calls the plugin callback. AzuraCast continues
  to select songs.
- The mixer uses Liquidsoap's native compressor as a sidechain detector with
  150 ms attack and 750 ms release.
- Background catalogue resolution avoids resolving the full sweeper playlist in
  each song request. The song callback limits overlay resolution to one second.
- A heartbeat renews reservations and reports actual playback or cancellation.
  Prefetch does not advance rotation.
- Rendered tests cover normal playback, skipping, live takeover and an unavailable
  planning API. They check onset, ducking, tail, song metadata and reservations.
- Effective AutoCue annotations include cached values even when native cue fields
  are blank. Cue-in is subtracted once and loudness is applied once.

## Scope and storage

The plugin creates or reuses the existing AzuraCast custom field `intro_end`.
Its authenticated cue endpoint updates only that entry; it does not replace the
full custom-field collection. Settings and rotation state remain in the station
configuration directory. The plugin defines no database tables, review state,
manual locks, vetoes or detection metadata.

The configuration page provides the sweeper playlist, mixing settings and a
waveform for viewing and setting `intro_end`. Intro values can also be edited in
AzuraCast's normal Custom Fields UI or through the plugin's one-field API.
There is no review, veto or approval workflow.

## Remaining validation

The integration depends on exact Liquidsoap configuration insertion points and
uses a sidebar script because AzuraCast has no matching navigation hook. Validate
these after upstream changes. A disposable station must still exercise actual
permissions, installation and live playback before on-air use.
